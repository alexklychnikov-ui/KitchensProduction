# Руководство пользователя — АртКухня

Инструкция для владельца и менеджера: Telegram-бот, веб-админка, заявки, каталог.

**Веб-админка:** [kitchen.alexklyvibe.ru](https://kitchen.alexklyvibe.ru)  
**Бот:** `@Alex_KichenProduction_bot`

---

## 1. Что умеет бот для клиента

- Отвечает на FAQ: цена, сроки, материалы, доставка, гарантия.
- **Подбор кухни** — пошаговая воронка с фото и ценами:
  1. Стиль (карусель с фото)
  2. Длина кухни (можно просто `3` или `3.5 м`)
  3. Планировка (прямая / угловая / П-образная)
  4. Фасады, столешница, фурнитура — снова карусель, в подписи цена за пог.м
  5. Ориентир по бюджету
  6. Телефон → заявка менеджеру
- **Вопросы прямо в воронке** — можно спросить «это все фасады?», «сколько доставка?»; бот ответит с учётом текущего шага и вернёт к выбору.
- **Запрос живого менеджера** — если клиент пишет «менеджер», «оператор», «мне нужен человек», бот **сначала попросит телефон**, потом передаст заявку в группу с уже выбранной конфигурацией.
- Голосовые сообщения (распознавание речи).
- Эскалация сложных обращений в группу менеджеров.

Клиент запускает подбор: `/start` → **«Подобрать кухню»** или пишет «хочу подобрать кухню».

---

## 2. Заявки

После ввода телефона (или после запроса менеджера + телефон):

- Заявка сохраняется в базе (`orders`).
- Менеджеру приходит уведомление в Telegram-группу (эскалация).
- Заявку можно посмотреть:
  - **Веб** → вкладка **«Заявки»** (телефон, конфигурация, диалог).
  - **Telegram** → `/admin` → **«Заявки»**.

> На вкладке «Заявки» поле поиска должно быть **пустым**. Если там случайно оказался логин `admin` — список будет пустым. Очистите поле или нажмите «Сбросить».

## 3. Веб-админка

Логин: из настройки `ADMIN_DASHBOARD_USER` (обычно `admin`).  
Первый пароль: **1111** — сразу смените в **Настройки → Смена пароля**.

### Вкладки

| Вкладка | Что делать |
|---------|------------|
| **Обзор** | Статистика, быстрые ссылки |
| **Заявки** | Список заказов, детали, переписка |
| **Каталог** | Стили, фасады, столешницы, фурнитура + **загрузка фото** |
| **Прайс** | Классы кухонь, столешницы, **сборы (доставка, монтаж)** |
| **FAQ** | Ответы бота (кроме доставки — см. ниже) |
| **Эскалация** | Триггеры передачи менеджеру |
| **Настройки** | Часовой пояс, **город**, бренд, пароль, журнал |
| **Менеджеры** | Контакты, Telegram, график, маршрутизация эскалации, фирменные фразы |

### Город и ответ про доставку

Ответ бота на вопросы про **доставку** формируется автоматически:

- **Город** — поле **«Город»** в Настройках (например, Иркутск → «По Иркутску…»).
- Если город пустой — подставляется город по **часовому поясу**.
- **Суммы** — из вкладки **Прайс → Сборы** (порог бесплатной доставки, цена по городу, за город, ₽/км).

Меняете город или тарифы в дашборде — бот сразу отвечает по-новому. Текст FAQ-ключа «доставка» вручную можно не править.

### Менеджеры и эскалация

Вкладка **Менеджеры** (или **Настройки → Менеджеры**):

- Три профиля: продажи, техника, дежурный (жалобы / вне часов).
- Телефон, Telegram, email, подпись графика.
- Рабочие часы студии (Пн–Пт, Сб) + **часовой пояс** из Настроек.
- Шаблоны фраз при передаче менеджеру (`{name}`, `{pronoun}`).

Бот при эскалации:

- Выбирает менеджера по типу обращения.
- Пишет клиенту по фирменному стилю (не сухое «передано оператору»).
- Вне рабочего времени добавляет: «менеджер ответит …» с учётом часового пояса.
- В группу уходит карточка с контактами ответственного и SLA-напоминание через N минут.

### Брошенная воронка

Если клиент начал подбор и не отвечал **N минут** (по умолчанию 10, настраивается в **Менеджеры → Таймаут брошенной воронки**):

- Менеджеру уходит эскалация с частичными данными (стиль, длина, шаг).
- Запись попадает в **Журнал эскалаций → Брошенная воронка**.
- Менеджер сам решает, связываться или нет.

### Журнал эскалаций

**Обзор → Журнал эскалаций** (или быстрый чип):

| Фильтр | Что показывает |
|--------|----------------|
| Все | Все эскалации |
| С заказом | Завершились оформлением заявки |
| Без заказа | Триггеры, голос, брошенная воронка и т.д. |
| Брошенная воронка | Только таймауты |

У записи с заказом — ссылка «Открыть заявку».

### Фото в каталоге

1. **Каталог** → выберите категорию (Стиль / Фасады / …).
2. У позиции нажмите **«Фото»** → выберите файл с диска.
3. Рекомендации: горизонталь 4:3, 1200×900, до 5 МБ — обрежется автоматически.
4. Фото хранится **в базе данных**, не в папке на сервере.
5. После загрузки превью обновится сразу; в боте фото появится в карусели (при первой отправке кэшируется в Telegram).

## 4. Админ в Telegram

Команда `/admin` (только для id из `TELEGRAM_ADMIN_IDS`):

- **Заявки** — последние заказы, краткая карточка.
- **Сводка** — цифры по базе.
- **Ссылка на веб-дашборд** — FAQ, прайс, каталог, настройки.

Старые команды `/cfg_*` сохранены, но удобнее править всё в вебе.

## 5. Когда бот зовёт менеджера

- Явный запрос менеджера / человека / оператора (**сначала телефон**, потом передача).
- Жалоба, претензия, договор, точный расчёт, замер.
- Фото или документ от клиента.
- Длинный диалог без решения.
- Проблема с голосовым после повторной попытки.
- **Новая заявка** из воронки подбора (с телефоном).

Сообщения приходят в чат `TELEGRAM_CHAT_ID` с телефоном и выбранными параметрами кухни.

## 6. Подготовка (один раз)

1. Создать бота в BotFather, получить токен.
2. Добавить бота в группу менеджеров, взять `chat_id`.
3. Заполнить `.env` (см. `.env.example`).
4. PostgreSQL обязателен для продакшена и админки.
5. В дашборде задать **город** и **прайс → сборы** (доставка).
6. Запустить сервисы бота и админки (или локально для теста).

Минимум для работы:

```
TELEGRAM_BOT_TOKEN
TELEGRAM_CHAT_ID
TELEGRAM_ADMIN_IDS
DATABASE_URL
PROXY_API_KEY
PROXY_BASE_URL
OPENAI_MODEL_VOICE
ADMIN_DASHBOARD_USER
ADMIN_SESSION_SECRET
CATALOG_PUBLIC_BASE_URL
```

## 7. Быстрая проверка

**Воронка:**

1. `/start` → «Подобрать кухню».
2. Листайте стили ◀️ ▶️, выберите один.
3. На шаге стиля спросите: `это весь выбор фасадов?` — бот объяснит шаг и подскажет дальше.
4. Введите длину: `2.7`.
5. Пройдите фасады / столешницу / фурнитуру.
6. Подтвердите ориентир → введите телефон.
7. Проверьте заявку в дашборде и уведомление в группе.

**Доставка (город из настроек):**

1. Дашборд → **Настройки** → город `Иркутск` (или свой).
2. **Прайс → Сборы** — проверьте тарифы доставки.
3. В боте на любом шаге воронки: `сколько стоит доставка?` — в ответе ваш город и актуальные суммы.

**Запрос менеджера:**

1. На шаге ориентира напишите: `мне нужен человек`.
2. Бот попросит телефон → введите `+7 9XX …`.
3. В группе — уведомление с телефоном и конфигурацией.

**FAQ:**

- Напишите боту: `какая цена?`

## 8. Частые проблемы

| Проблема | Решение |
|----------|---------|
| Бот молчит на «Подобрать кухню» | Проверить логи `kitchens-bot.service`, `DATABASE_URL` |
| Бот не отвечает на вопрос в воронке | Перезапустить `kitchens-bot.service` (нужна свежая версия) |
| В дашборде нет заявок | Очистить поиск на вкладке «Заявки» |
| В ответе про доставку старый город | Проверить **Настройки → Город**, переспросить в боте |
| Фото загрузилось, но не видно | Ctrl+F5, перезалить фото |
| Фото в боте не показывается | Загрузить фото в каталоге; проверить `CATALOG_PUBLIC_BASE_URL` |
| Менеджеру пришло без телефона | Клиент должен ввести номер после запроса менеджера |
| Admin-команды не работают | Ваш id не в `TELEGRAM_ADMIN_IDS` |
| Голос не распознаётся | Проверить `PROXY_API_KEY`, качество записи |
| Не пишет в группу | Неверный `TELEGRAM_CHAT_ID` или нет прав у бота |
